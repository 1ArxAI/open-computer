Manual Step-by-Step Setup

Prefer running it yourself? Follow these 4 easy steps on Ubuntu 22.04 / 24.04.

1

Create a Dedicated User

Log in as root on your server and create a standard user:

adduser suop && usermod -aG sudo suop && su - suop
2

Clone and Run the Installer

Run the 1-command installer script as your new user:

git clone https://github.com/shieldspprt/open-computer.git && cd open-computer && bash install.sh
3

Open in Your Browser

Forward port 8000 to your local machine via SSH:

ssh -L 8000:127.0.0.1:8000 suop@your-server-ip

Then visit http://localhost:8000 (or connect a free Cloudflare Tunnel for public domain access).

4

Add Model Key & Start Chatting

Sign in with your Linux username and password, paste your OpenRouter/Anthropic/OpenAI key in Settings, and you're ready!
