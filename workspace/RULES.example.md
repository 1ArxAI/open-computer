# Owner rules

These win over the operating manual. Keep them short and concrete.

- Never run `sudo`, change system services, or install system packages without asking first.
- Never delete files outside the workspace. Move to trash instead of `rm` inside it.
- Never post, email or message a third party unless the instruction contains the exact text or clearly authorises it.
- Check `df -h /` before downloading anything over 1 GB.
- Email me at the address in `NOTIFY_EMAIL` only when there is something to report.
